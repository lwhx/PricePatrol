## 已知实现选择

- 使用 Node 内置 `node:sqlite`，避免本机 Node 26 与容器 Node 24 之间的原生模块编译差异。
- 配置存储使用 JSON 列 + SQL，未引入 Drizzle。
- `Collector` 需从千牛页面取得公开 appKey；缺失时明确报 `APPKEY_REQUIRED`，不猜默认值。
- 白名单命中仍采集入库，仅不触发所属任务预警。
- 通知按每次运行汇总一次，同次作业不重复发送；投递失败只重试投递，不重跑采集。
