# Repository接口补充

新增子任务只拥有 server/src/database.ts、server/src/query.ts、server/src/export.ts、server/test/{database,query,export}.test.ts。不修改其他文件。

父代理已实现server/src/domain.ts和security.ts，可复用：moneyCents、moneyText、rowKey、formatDiscount、evaluateCondition/evaluateRules、whitelistReason、parseProductIds；Vault封装seal/open。

导出 `Store` 类 (`server/src/database.ts`)：
- constructor(filename:string,encryptionKey:string)，:memory:可用；公开 `db:DatabaseSync`；close()。
- getConfig<T>(key:string,fallback:T):T；setConfig(key,value):void。
- listShops():Shop[]；getShop(id):Shop|undefined；saveShop(shop:Shop,credentials?:VerifiedAccount):void；getCredentials(id):VerifiedAccount（未配置抛错），凭据Vault加密；给API的Shop不能有凭据。
- listTasks():MonitorTask[]；getTask(id):MonitorTask|undefined；saveTask(task):void；deleteTask(id):void（保留run历史，task表softdeleted）。
- listRuns():RunRecord[]（最近200），getRun(id):RunRecord|undefined，saveRun(run:RunRecord):void；RunRecord = Run & {taskSnapshot:MonitorTask|null; mergedSchedules?:number}，可在database.ts导出。无secret。
- saveProduct(runId:string,product:ProductCollection):void：作业必须存在，shop从run来验证；PriceRow从CollectedRow转化。成功行写最新和按run固定快照；product.error且无rows则旧同商品latest行标stale，并将失败状态保存该run快照，后续预警排除。ID=rowKey，stock等数据不丢，金额检查，last success旧值可以保留但stale=true。同run重复回调幂等。成功更新的历史快照不能覆盖其他已结束run。
- getRunPrices(runId):PriceRow[]，history(shopId,productId,skuId?):PriceRow[]（最近1000）；compare(leftRunId,rightRunId):object[]。
- annotate(shopId,productIds,tags?:string[],note?:string):number。
- query(input:QueryInput):QueryResult，SQL查询数据库，支持跨页全部筛选、折扣精确、商品视图any/all/未知。额外`queryAll(input): (PriceRow|ProductRow)[]`用于导出（全部条件和排序，不只是page）。schema/UDF由你定，若SQL数值精度难可注册JS domain函数在SQLite内做exact过滤，不能全库拉回API进程再分页。
- saveAlert(alert:Alert):void（id+run/shop/product/sku去重）、listAlerts(filters?:{state?:string;shopId?:string;runId?:string}):Alert[]（最多1000）、getAlert(id):Alert|undefined、updateAlert(id,patch):Alert。
- saveQuery(name,query):{id,name,query}；listQueries():{id,name,query}[]；deleteQuery(id)。
- overview():Overview；backup(destination:string):Promise<void>采用node:sqlite backup或VACUUM INTO一致性方案；cleanup(before:string):number 保护alert引用run。

export.ts导出 `buildExport(store:Store,input:ExportInput):ExportResult`、`getExport(store,token):ExportResult|undefined`；由父API调用。创建内容与预览固定快照，不持有长事务；内容保存在SQLite或内存TTL有界，一次同步读确保快照一致。scope selected/page/all；多店商品ID复制按shop+product去重、SKU字段不可吞行，商品视图默认匹配SKU或allSkus选项；字段名称取PriceRow驼峰（shopName,productId,title,sourceUrl,skuId,specs,seatSpec,color,backendPrice,before,after,discount,saving,priceDifference,detailFetchedAt,backendFetchedAt,updatedAt,status,error,note,tags），ProductRow对应聚合字段，headers中文映射。copy格式按contracts。选中id为PriceRow/ProductRow.id。默认示例前5行，含header和字段顺序；bytes>5MiB或rows>20000推荐download，不截断。getExport返回固定内容不重新查询。

父代理后续负责API/worker/调度，按上述接口编写。发现必要变更先报告，别改shared/contracts.ts。
