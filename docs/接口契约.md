# 实现接口契约（由父代理维护）

所有API在 /api；fetch credentials:'include'。非2xx JSON `{error:string}`。Zod输入错误400。首次访问 GET /api/auth/status -> `{configured:boolean,authenticated:boolean}`；POST /api/auth/setup `{password}`；POST /api/auth/login `{password}`；POST /api/auth/logout。首次setup产生持久管理员hash，password最少10字。其余请求需session cookie，变更请求要求同源或无Origin本机CLI，浏览器跨域拒绝。

类型见 shared/contracts.ts，导入相对路径含.js后缀（tsx支持）。

- GET /api/overview -> Overview。
- GET /api/shops -> `{shops:Shop[]}`。
- POST /api/shops `{name?:string,platform,cookies:string|CookieRecord[],userAgent?:string,appKey?:string}` -> `{shop:Shop}`，父代理调用collector.verify，不存未验证账号。
- PATCH /api/shops/:id `{name?,enabled?,cookies?,userAgent?,appKey?}` -> `{shop}`；若改Cookie重新核验identity。DELETE /api/shops/:id -> `{ok:true}`，有历史时停用。
- POST /api/shops/:id/verify -> `{shop}`。POST /api/shops/:id/collect `{productIds?:string[]}` -> `{run:Run}`。
- POST /api/prices/query QueryInput -> QueryResult；GET /api/prices/history?shopId&productId&skuId -> `{rows:PriceRow[]}`；POST /api/prices/compare `{leftRunId,rightRunId}` -> `{rows:object[]}`。
- PATCH /api/prices/annotations `{shopId,productIds:string[],tags?:string[],note?:string}` -> `{updated:number}`。
- POST /api/exports ExportInput -> ExportResult（返回固定快照content与preview，超过复制上限推荐下载）。GET /api/exports/:token/download -> 该快照文件。
- GET /api/tasks -> `{tasks:MonitorTask[]}`；POST /api/tasks TaskInput -> `{task}`；PATCH /api/tasks/:id TaskInput的部分 -> `{task}`；DELETE /api/tasks/:id -> `{ok:true}`。
- POST /api/tasks/:id/run -> `{run}`；POST /api/tasks/:id/duplicate -> `{task}`，副本暂停。
- POST /api/tasks/:id/whitelist `{productIds?:string[],titleKeywords?:string[]}` -> `{task,added:number,existing:number}`。
- POST /api/tasks/:id/whitelist/preview `{productIds:string[],titleKeywords:string[]}` -> `{count:number,products:{productId,title}[]}`。
- GET /api/runs -> `{runs:Run[]}`；POST /api/runs/:id/stop -> `{run}`；POST /api/runs/:id/resume -> `{run}`；POST /api/runs/:id/retry -> `{run}`（关联新作业）。
- GET /api/alerts?state=&shopId=&runId= -> `{alerts:Alert[]}`（最多1000）；PATCH /api/alerts/:id `{state?,note?}` -> `{alert}`。
- GET /api/queries -> `{queries:{id,name,query:QueryInput}[]}`；POST /api/queries `{name,query}` -> `{id,name,query}`；DELETE /api/queries/:id -> `{ok:true}`。
- GET /api/settings -> `{notification:NotificationSettings,retentionDays:number,timezone:string}`。
- PUT /api/settings `{sendKey?:string,notificationEnabled?:boolean,retentionDays?:number}` -> 同GET。空SendKey明确清除，不回显。
- POST /api/notifications/test -> `{accepted:true}` 或错误，明确是对配置渠道实际发测试消息；不自动调用。
- POST /api/runs/:id/notify -> `{accepted:true}`，重试本次汇总投递。
- POST /api/maintenance/backup -> 下载一致性sqlite备份。POST /api/maintenance/cleanup `{before:string}` -> `{deleted:number}`，保护预警证据。

通知模块由子任务提供：`server/src/integrations/serverchan.ts` 导出 `sendServerChan(sendKey:string,message:NotificationMessage,options?:{fetch?:typeof fetch}):Promise<{accepted:boolean;requestId?:string}>`；`serverChanEndpoint(sendKey):string`。不要在错误message中放密钥/URL。支持SCT和sctp...酱3，以官方代码核实。

登录辅助模块由子任务提供：`server/src/integrations/browser-login.ts` 导出 `BrowserLoginService`，构造options `{dataDir:string}`，方法 `create(platform):Promise<{id:string}>`、`screenshot(id):Promise<Buffer>`、`action(id,{type:'click'|'type'|'press',x?,y?,text?,key?}):Promise<void>`、`cookies(id):Promise<CookieRecord[]>`、`close(id):Promise<void>`、`closeAll():Promise<void>`。运行在本机或Docker内同进程Playwright，无浏览器时返回明确依赖错误。API由父代理包装 `/api/login-sessions` POST `{platform}`；`/:id/screenshot` GET PNG；`/:id/action` POST action；`/:id/complete` POST `{name?,platform}`调用cookies和verify绑定Shop；DELETE `/:id`。提供真实截图/点击/输入辅助界面，不伪造登录，用户手动扫码/验证。

父代理负责package.json、锁文件、共享类型、server核心/API/数据库/调度；前端子任务只改web/**；collector子任务只改server/src/collector/**、server/test/collector*.test.ts；integration子任务只改integrations、integration测试、Docker/compose/README/.github，不改共享契约。有缺口向父代理报告，不自行改契约。
